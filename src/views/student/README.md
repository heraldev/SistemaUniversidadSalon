# Vistas del alumno

- Aquí van las pantallas que pueden ver los alumnos.
- Usar las clases de `src/App.css` para conservar el mismo diseño.
- Los datos de carreras son temporales; después se conectarán al backend.
- El botón «Ver más información» queda sin acción hasta que se cree la pantalla de detalle.
- No agregar iconos ni librerías nuevas para cambios simples.
