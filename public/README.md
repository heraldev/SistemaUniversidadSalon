# public — Recursos públicos

- Guardar aquí imágenes o íconos estáticos que no requieran importación desde TypeScript.
- Usar nombres descriptivos, minúsculas y sin espacios.
- Optimizar imágenes para que carguen rápido en celular.
- No subir archivos privados ni credenciales; todo en `public/` será accesible al visitante.
